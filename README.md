# 🏡 Global Airbnb Performance Dashboard

An end-to-end data analytics project exploring global Airbnb listings, market trends, host dynamics, and customer satisfaction metrics.

---
**💡 Short Description / Purpose**

This project provides a comprehensive analysis of global Airbnb data, visualizing key performance indicators for listings, hosts, property types, and pricing.
The dashboard is designed to uncover trends in market share, geographic distribution, and customer ratings, allowing users to understand the drivers behind Airbnb's rapid growth and host/guest dynamics across major cities.

---
**💻 Tech Stack**

The dashboard was built using the following tools and technologies:
- 📊 Power BI Desktop – Data visualization and interactive dashboard creation.
- ⚡ Power Query – Data transformation, cleaning, and preparation for analysis.
-  🔍 DAX – Calculated measures, dynamic visuals, and conditional logic.
- 🔗 Data Modeling – Establishing cross-filtering and relationships across tables.
---
**🗄️ Data Source**

The dataset for this project was obtained from Maven Analytics (Airbnb listings and reviews dataset).
You can access and explore the data here: https://mavenanalytics.io/data-playground

---
**📌 Key Features & Highlights**

- 🏢 Overall KPIs: Tracking over 279,000 listings and 5 million+ sorted reviews across 10 cities and 182,000+ hosts.
- 📈 Listing History: Trend lines visualizing total listings over time by room type (Entire Place, Hotel Room, Private Room, Shared Room).
- 🏙️ Market Share by City: Comparison of listing counts and total reviews across regions—highlighting major hubs like Paris and NYC.
- ⭐ Detailed Ratings: Evaluation of destinations based on accuracy, cleanliness, check-in, communication, location, and value.
- 🛡️ Trust & Verification: Insights into host verification status and profile picture usage.
- 📅 Seasonality Analysis: Review share trends per month reflecting peak travel periods.
---
**🚀 Insights & Business Opportunities**

Travel agencies and developers can utilize these insights to identify high-potential expansion regions, recognize popular room types, and optimize pricing strategies based on guest preferences.
